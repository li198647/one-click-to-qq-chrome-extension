一键发到 QQ · 完整安装包 v1.0.1
（浏览器扩展 + 本地桥）
================================================================

这个包里有两部分，缺一不可：

  extension/   浏览器扩展 —— 浏览器里的入口，负责抓内容、发请求
  bridge/      本地桥（Python）—— 真正把消息送到 QQ 的程序
  README.md    完整说明文档

只装扩展的话，弹窗能打开、能看到候选，但点「立即发送」会失败
（弹窗顶部会显示红色「离线」并写明原因，不会静默失败）。

================================================================
第一步：装浏览器扩展
================================================================
1. 找一个「以后不会删、也不会挪走」的文件夹放这个包，例：D:\一键发到qq\
2. 打开浏览器，地址栏输入：chrome://extensions
3. 打开右上角「开发者模式」（Developer mode）
4. 点左上角「加载已解压的扩展程序」，选中本包里的 extension 文件夹
   （里面能看到 manifest.json 的那一层）
5. 成功后地址栏右侧出现一只【黑色企鹅】

   ！！！extension 那个文件夹不能删、不能挪，否则扩展失效！！！

快捷键：Ctrl+B（Mac 为 Command+B）
没反应就去 chrome://extensions/shortcuts 手动设一次。

================================================================
第二步：跑起本地桥
================================================================
桥需要电脑上有 Python 3.10 以上。

1. 装依赖（只需一次）。打开命令行，执行：
       pip install qq-botpy aiohttp Pillow

   如果装不上（报 No matching distribution found），多半是代理干扰，
   换国内源再来一次：
       pip install -i https://mirrors.aliyun.com/pypi/simple/ qq-botpy aiohttp Pillow

   （Pillow 只用于发图片：探测格式、超过 20MB 自动缩尺寸。
     不装也能启动，只是发图时会提示缺少它，发文字完全不受影响。）

2. 填配置。把 bridge\config.example.json 复制一份改名为 config.json，
   然后用记事本打开，只填两项：
       "appid"    → QQ 开放平台 → 你的机器人 → 开发设置 → AppID
       "secret"   → 同一页面的 AppSecret
   其余字段保持默认即可（sandbox 保持 true）。

   ⚠️ config.json 里有你的密钥，不要发给别人、不要提交到 GitHub。

3. 启动。双击 bridge\start_bridge.bat（或命令行 python qq_bridge.py）。
   看到「机器人「我的速记本」启动成功！」就是好了。
   这个窗口要一直开着 —— 关掉它，浏览器里的扩展就发不出去了。

4. 第一次用：在手机 QQ 里给机器人发一句话（随便一个字）。
   程序会记下你的 openid，之后就能主动给你发消息了。
   （腾讯限制：必须你先发过一次，机器人才能主动找你。）

5. 验证：打开 http://127.0.0.1:18761/health
   看到 "bot_ready": true 且 "has_openid": true 就成了。

================================================================
第三步：用起来
================================================================
在浏览器里选中一段文字（或先复制），按 Ctrl+B。
手机 QQ 的「我的速记本」里就会收到。

点地址栏那只企鹅图标可以：看这次将要发送的完整内容、从最近 4 条里改选、
看桥是否在线、手动点发送（不想用快捷键时）。

发图片（v1.0.1 起）：两种办法，选一个顺手的
  · 先截图 / 在网页图片上右键「复制图片」，然后点图标或按 Ctrl+B
  · 直接在网页图片上右键 →「发送此图片到 QQ」
弹窗里会明确标出这次发的是图片：候选行前面有个小图标、写着
「图片 · 1080×2400 · 2.4 MB」，上面那块换成这张图的缩略图。

  注意：需要登录才看得到的网页图片（网盘、后台系统里的）右键发不了，
  浏览器不允许扩展后台带着你的登录状态去下载。这种请改用「复制图片」。

================================================================
为什么不是 .crx 文件？
================================================================
Chrome 从 2018 年起禁止安装非 Chrome 应用商店来源的 .crx：
双击提示「可能已损坏」，拖进扩展页也会被拦截。
「解压 + 加载已解压的扩展程序」是目前唯一可行的本地安装方式。
