## 一键发到 QQ · v1.0.1

在浏览器里选中一段文字、或复制一段内容，按一下 `Ctrl+B`，**内容就发到你手机 QQ 上了**。
这一版起，**图片也是一样一键**。

电脑浏览器 → 本地桥 → QQ 官方机器人 → 手机 QQ，三段式链路。

---

### 下载哪个？

| 文件 | 里面有什么 | 什么时候下这个 |
|---|---|---|
| `one-click-to-qq-extension-v1.0.1.zip` | **只有浏览器扩展** | 你已经装好过桥程序，只想更新扩展 |
| `one-click-to-qq-kit-v1.0.1.zip` | **扩展 + 本地桥 + 完整说明** | **第一次装，选这个** |

> 两个包里都带一份 `!安装说明-先看这个.txt`，解压后照着走就行。

---

### 怎么装（三步）

1. **解压**到一个以后不会删、不会挪走的文件夹，例如 `D:\一键发到qq\`
2. 浏览器打开 `chrome://extensions` → 打开右上角**开发者模式** → 点**加载已解压的扩展程序** → 选中里面的 `extension` 文件夹
3. 完整包还要跑起本地桥：`pip install qq-botpy aiohttp Pillow` → 把 `bridge\config.example.json` 复制成 `config.json` 并填入自己的 AppID / AppSecret → 双击 `bridge\start_bridge.bat`

装好后地址栏会多出一只黑色小企鹅。在网页里选中文字按 `Ctrl+B` 即可发送；
点图标可以先看这次将要发送的完整内容、从最近 4 条里改选、看桥是否在线。

> 从 `1.0.0` 升上来的话：桥程序要**更新并重启**（新版的 `qq_bridge.py` 才会认图片），
> 扩展在 `chrome://extensions` 点一下「重新加载」。历史数据无需迁移。

---

### ⚠️ 为什么不是 .crx？

Chrome 从 2018 年起禁止安装非 Chrome 应用商店来源的 `.crx`（双击提示「可能已损坏」，
拖进扩展页也会被拦截）。**「解压 + 加载已解压的扩展程序」是目前唯一可行的本地安装方式。**

另外提醒一句：`extension` 那个文件夹**不能删、不能挪**，否则扩展会失效。

### 这一版新增：一键传图片

两个入口，都是一下：

- **剪贴板里的图片** —— 用截图工具截个图（或在网页图片上右键「复制图片」），然后点扩展图标或按 `Ctrl+B`
- **右键网页图片** —— 在网页图片上右键 →「**发送此图片到 QQ**」

弹窗里会**明确标出这一次要发的是图片**，不会让你怀疑发错了：

- 候选行前面一个小图标徽标，写着「图片 · 1080×2400 · 2.4 MB」
- 上面的「将要发送」那块换成**这张图的真缩略图**（不再是文字框）

三条设计上的取舍，都是被硬限制逼出来的：

- **图片不进候选历史**（历史里仍然只有文字）。浏览器的会话存储配额只有 10MB，而图片转 base64 要膨胀 1/3 —— 4 张 2MB 的截图就能把它撑爆，一旦撑爆是**整个历史写入失败**，连你攒的文字一起搞挂
- **剪贴板里同时有图和文字时，仍然发文字** —— 不破坏已经在用的行为
- **没拿到图片就明确报错，绝不静默换内容发出去**

顺手还做了两件兜底：

- 超过 20MB 的图会被 QQ 降级成「文件卡片」（手机上要点开下载才看得见），所以**超过 20MB 会自动缩一次尺寸**（只降分辨率、不换格式，截图上的小字不会糊），缩过会弹通知告诉你
- 官方文档对图片格式的说法自相矛盾，所以**先按原格式发，被拒就转成 PNG 再试一次**

### 已知限制

- 必须先给机器人发过一次消息（腾讯的主动消息限制）
- 电脑关机、或本地桥进程没开 → 发送会明确失败
- 只能装在 Chrome / Edge 这类 Chromium 内核浏览器上（需要开发者模式）
- **需要登录才看得到的网页图片，右键发不了** —— 浏览器不允许扩展后台带着你的登录状态去下载。这类图请改用「复制图片」
- 图片不进候选历史；发图比发文字慢一点（几 MB 的图大约多等 1 秒）
