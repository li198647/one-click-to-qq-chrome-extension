## 一键发到 QQ · v1.0.0

在浏览器里选中一段文字、或复制一段内容，按一下 `Ctrl+B`，**内容就发到你手机 QQ 上了**。
不用切窗口、不用拖文件、不用扫码。

电脑浏览器 → 本地桥 → QQ 官方机器人 → 手机 QQ，三段式链路。

---

### 下载哪个？

| 文件 | 里面有什么 | 什么时候下这个 |
|---|---|---|
| `one-click-to-qq-extension-v1.0.0.zip` | **只有浏览器扩展** | 你已经装好过桥程序，只想更新扩展 |
| `one-click-to-qq-kit-v1.0.0.zip` | **扩展 + 本地桥 + 完整说明** | **第一次装，选这个** |

> 两个包里都带一份 `!安装说明-先看这个.txt`，解压后照着走就行。

---

### 怎么装（三步）

1. **解压**到一个以后不会删、不会挪走的文件夹，例如 `D:\一键发到qq\`
2. 浏览器打开 `chrome://extensions` → 打开右上角**开发者模式** → 点**加载已解压的扩展程序** → 选中里面的 `extension` 文件夹
3. 完整包还要跑起本地桥：`pip install qq-botpy aiohttp` → 把 `bridge\config.example.json` 复制成 `config.json` 并填入自己的 AppID / AppSecret → 双击 `bridge\start_bridge.bat`

装好后地址栏会多出一只黑色小企鹅。在网页里选中文字按 `Ctrl+B` 即可发送；
点图标可以先看这次将要发送的完整内容、从最近 4 条里改选、看桥是否在线。

---

### ⚠️ 为什么不是 .crx？

Chrome 从 2018 年起禁止安装非 Chrome 应用商店来源的 `.crx`（双击提示「可能已损坏」，
拖进扩展页也会被拦截）。**「解压 + 加载已解压的扩展程序」是目前唯一可行的本地安装方式。**

另外提醒一句：`extension` 那个文件夹**不能删、不能挪**，否则扩展会失效。

### 这一版有什么（v1.0.0 = 首个正式版）

- **三段式发送链路**：选中文字 → 剪贴板 → 页面标题+链接，依次兜底，三级都空才报错
- **发前可预览、可改选**：弹窗里「将要发送」的文字单独框出，下面列最近 4 条候选，点哪条改哪条
- **剪贴板历史**：保留最近 4 次内容，只存内存、关掉浏览器即清空（剪贴板里可能有过密码，所以不落盘）
- **所见即所发**：列表和真正发送走同一个取值函数，不存在"看到 A 发出 B"
- **失败必报错、绝不静默降级**：读不到剪贴板、页面受限、桥离线，都会在弹窗里写明原因
- **黑色企鹅图标**：侧身几何剪影，与 QQ 的正面圆胖企鹅明确区分；白底保证在深色工具栏上也看得见

### 已知限制

- 必须先给机器人发过一次消息（腾讯的主动消息限制）
- 电脑关机、或本地桥进程没开 → 发送会明确失败
- 只能装在 Chrome / Edge 这类 Chromium 内核浏览器上（需要开发者模式）
- 只发文字，暂不支持图片
